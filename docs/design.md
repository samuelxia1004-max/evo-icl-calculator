# Interface direction

Audience: ophthalmology researchers and conference readers. Main task: inspect an anatomical scenario alongside the reconstructed model's uncertainty and validation evidence.

Direction: an ophthalmic research workstation, informed by the side-by-side review, worklist navigation and configurable views in ZEISS FORUM / HEYEX 2. This is an independent interface, with no vendor affiliation or copied assets.

Tokens: deep navy `#10283F`, clinical blue `#176BBD`, sea teal `#0D8B84`, frost `#F2F6FA`, slate `#687C90`, amber `#A76920`. White instrument panels; 12–18 px corners; subtle borders; 4/8 px spacing rhythm. System sans for Chinese and ordinary copy, tabular numeric type for measurements. No persistent animation. Keyboard-visible focus and reduced-motion support.

Layout: a fixed 224 px navigation rail, a compact utility bar, a contextual title and two-column workspace. In the main workspace an input panel stays separate from a wide graphical result panel. Eye selection controls a consistent context across scenario, sensitivity and follow-up views.

Signature: an interactive anterior-segment and sulcus geometry panel, paired with an honest prediction interval. The diagram is illustrative, not a physical simulation or an imaging-derived reconstruction.

Pages: research overview; vault experiment; parameter scenarios; longitudinal research; import and batch validation; study evidence; conference poster and reporting.

Data: generated aggregate JSON, a jointly fitted model trained on 2022–2024, and synthetic demonstrations. No embedded real individual records. Session inputs stay in memory; downloaded exports are explicit user actions. Sharing research parameters requires an explicit disclosure checkbox.
